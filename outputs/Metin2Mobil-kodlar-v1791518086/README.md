# Metin2Mobil kod paketi

Bu klasör inceleme için küçük tutulmuş, kod odaklı bir kopyadır.

- `python/packs/`: Açılan EterPack arşivlerindeki `.py` ve `.py.bak` dosyaları.
- `python/remote/`: Manifestten doğrudan indirilen Python dosyaları.
- `java/`: APK içindeki DEX kodundan decompile edilen Java kaynakları.
- `native/`: ARM64 istemci motorunun tam ve seçilmiş C-benzeri sözde kodu, beş assembly tamamlayıcısı, sembol envanteri ve güvenlik raporları.

Tam varlıklar ve doğrulama raporları yanındaki `Metin2Mobil-full-v1791518086` klasöründedir.
